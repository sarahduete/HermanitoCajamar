# 🌮 Hermanito Cocina Mexicana

Site institucional para restaurante mexicano

O Hermanito Cocina Mexicana é um projeto desenvolvido com o objetivo de apresentar o restaurante, seus pratos e sua identidade visual por meio de uma página institucional.

🔗 [**Acessar o site**]([COLE_AQUI_O_LINK_DO_SITE](https://hermanitocajamar.lovable.app))

## 📖 Sobre o projeto

O projeto surgiu da ideia de criar uma presença digital para o Hermanito Cocina Mexicana, reunindo informações sobre o restaurante e apresentando suas opções de culinária mexicana.

A proposta foi desenvolver um site que transmitisse a personalidade da marca, destacando pratos como tacos, burritos, quesadillas e nachos, além de proporcionar uma navegação simples e agradável para os visitantes.

## 💻 Como foi desenvolvido

O desenvolvimento começou com a definição da identidade visual e o planejamento da estrutura do site.

A proposta visual foi inspirada na culinária mexicana, utilizando uma combinação de vermelho e amarelo para transmitir a personalidade do restaurante e criar uma apresentação marcante.

Em seguida, trabalhei na estrutura utilizando HTML, organizando as seções de apresentação, sobre o restaurante, pratos, cardápio e contato.

Na parte visual, utilizei CSS para desenvolver o layout, definir as cores, trabalhar a tipografia, organizar as imagens e ajustar os espaçamentos.

Também trabalhei na organização das informações para facilitar a navegação e destacar os principais elementos do restaurante.

## ⚙️ Funcionalidades

- Apresentação do restaurante.
- Seção sobre a marca.
- Destaque para pratos mexicanos.
- Apresentação do cardápio.
- Imagens dos produtos.
- Informações de contato.
- Links para redes sociais.
- Navegação entre as seções.
- Layout responsivo.

## 🛠️ Tecnologias utilizadas
